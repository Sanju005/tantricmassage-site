One-Click Blog Publisher

Fill the article, pick the hubs, and click `Post`. The app will create the article, update `blog/index.html`, add it to every selected hub, and update `sitemap.xml` automatically.

Post Details

Editorial

Use blank lines between paragraphs. Use `##` for H2, `###` for H3, and `-` for bullets.

Taxonomy

Comma-separated tags. These are separate from the place-page checkboxes below.
These drive the automatic hub and place-page inserts. Every selected place page will be updated after you click `Post`.

Media

Use a web path like `/blog/kuala-lumpur/images/example.jpg` or a full `https://...` image URL. Local `D:\...` paths are now converted when possible, but web paths are best.

SEO

One FAQ per line using `Question :: Answer`. These will become FAQ schema and an on-page FAQ section.
Optional raw JSON-LD object or array. It will be added as an extra schema block.
Server connected. Fill the form and click `Post`.

What This Updates

  • Creates `blog/your-slug.html`
  • Updates `blog/index.html`
  • Updates selected place pages
  • Updates matching blog hub pages when available
  • Updates `sitemap.xml`
WordPress-style fields Title, slug, excerpt, hub, category, tags, featured image, caption, and content.
SEO tools SEO title, meta description, canonical URL, robots, focus keyword, meta keywords, FAQ schema, and custom JSON-LD.
Auto-publish flow Still updates the blog index, related hubs, selected place pages, and sitemap in one step.
